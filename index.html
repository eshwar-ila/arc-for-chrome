Quick setup

  1. Install Arc for Chrome and open it from Chrome’s toolbar.
  2. Review the local-data notice, then choose a fresh setup or import a backup.
  3. Pin the extension to the toolbar for quick access.
  4. Optionally open chrome://settings/appearance, use Vertical tabs, and place Chrome panels on the left for the compact layout.

On macOS, the optional local companion can make the compact window transition and theme matching more reliable. Core sidebar features work without it.

Optional macOS helpers

These helpers run only on your Mac. They have no updater, analytics, network connection, or publisher server. Arc for Chrome’s core sidebar works without them.

Arc migration helper Creates one local .arcsidebar file containing Arc Spaces, folders, saved tabs, Archive, locally available history, and cached icons. Compact layout helper Makes the macOS window offset and Chrome theme matching reliable. Requires local Accessibility permission for /usr/bin/osascript.

Move your setup

From another Arc for Chrome profile

  1. Open Setup and privacy in the source profile.
  2. Select Export sidebar backup.
  3. In the new profile, select Sidebar backup and choose the downloaded JSON file.

From Arc on macOS

  1. Download and unzip the Arc migration helper.
  2. Open Arc once and wait for its sidebar to finish loading.
  3. Double-click Prepare Arc Migration.command. If macOS blocks it, Control-click it, select Open, then select Open again.
  4. In Arc for Chrome setup, choose Move from Arc and select the new .arcsidebar file from Downloads.

The import can preserve Spaces, Top Apps, saved tabs, folders, titles, order, Archive, locally available history, and cached icons. Arc’s official data export is available as a limited fallback.

Imports are read only after you choose a file and are processed locally.

Install the compact layout helper

  1. Download and unzip the compact layout helper.
  2. In Arc for Chrome setup, select Copy extension ID.
  3. Double-click Install Arc for Chrome Helper.command and paste the ID when asked.
  4. If prompted, allow /usr/bin/osascript in System Settings → Privacy & Security → Accessibility.
  5. Return to setup and select Recheck helper.

To remove it, run uninstall-macos-helper.sh. Arc for Chrome then uses Chrome’s built-in window API.

Help

The sidebar does not open

Open the toolbar extension menu, select Arc for Chrome, and pin it. You can also use Control+S on macOS or Alt+S elsewhere.

History or Archive is empty

History shows Chrome history available in the current Chrome profile. Archive shows recently closed Chrome tabs and windows. Arc history requires a local migration bundle.

Switch to the previous tab

Use Control+Q on macOS or Alt+Q elsewhere.

Remove all local extension data

Remove the extension from Chrome and choose to clear its data. The extension has no publisher account or remote copy to delete.
