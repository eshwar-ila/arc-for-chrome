Privacy policy

Effective October 29, 2026

Arc for Chrome has no accounts, analytics, advertising, tracking, or publisher-operated server. It does not send user data to the developer or third parties.

Data handled locally

To provide its visible features, the extension reads and handles the following information inside the user’s Chrome profile:

  • open tab URLs, titles, and favicons;
  • local Chrome browsing history;
  • recently closed tabs and windows;
  • user-created Spaces, folders, saved sites, Top Apps, names, ordering, preferences, and onboarding choices; and
  • files the user explicitly selects for migration, backup, or restore.

This information is used only to display, search, organise, restore, and navigate the sidebar features the user requests. It is processed and stored locally. The developer cannot access it.

No transmission, sale, or sharing

The extension does not transmit user data to the developer or any third party. It does not sell data, use data for advertising, build profiles, measure users, or determine creditworthiness. It contains no analytics or remote code.

Optional local macOS companion

If separately installed, the local companion communicates through Chrome Native Messaging on the same computer. It receives only numeric Chrome window bounds, or the extension ID needed to read Chrome’s locally stored theme choice. It does not receive tab URLs, browsing history, page content, account data, or network data.

Exports and imports

Export actions create a local file only after the user selects an export control. Imports are processed only after the user selects a file. Neither action uploads data.

Control and deletion

Users control the data by editing or deleting items in the sidebar, exporting a local backup, clearing extension storage, or removing the extension and its local data. There is no remote account or server-side copy.

Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Browsing activity is used only for the visible tab, history, archive, search, and navigation features requested by the user.

Changes

If the extension’s data practices change, this policy and the Chrome Web Store disclosures will be updated before the changed handling begins.
